2. Isaac: 씬 로드 → **브릿지 스크립트 실행 → HUD 실행 → Play** 순서 (`docs/run_guide.md` T1).
   **Play 중에 브릿지 스크립트를 다시 Run 하지 않는다.** 그때 만들어지는 `Articulation` 은
   Isaac 의 play 콜백을 놓쳐 `initialize()` 가 안 돌고, 컨트롤러 view 가 None 인 채로 남는다 —
   09-09 17:23 런이 정확히 이 경로였다. 09-10 수정으로 이 상태에서도 복구되지만(런 2 가 실증),
   애초에 겪지 않는 편이 낫다. Stop 후 **Play 만** 다시 누르는 것은 안전하다.

  (열린 조우 하강 실패 `open_stem_descent`) / 닫기(NW 보정 이동 `nw_base_y_nudge` 또는 그리퍼 닫기 실패 `after_descent`·`grasp=GRIPPER_CLOSE_FAILED`) / 파지 판정(빈손 등으로 배치 게이트에서
  차단, `grasp=GRASP_EMPTY` 등) / 후퇴(진입 역순 후퇴 실패 `retreat_failed`) / 예외(진입 뒤 `run()` 이 예외로 끝남, `run() raised after …`).
  칸 수 ≠ 시도 수면 Kit 로그의 overflow 경고를 같이 적는다(같은 과실 재시도는 칸을 두 개 먹는다).
- **당김 명령 실패 n** — 노드 로그 `[harvest_probe] 당김 명령 실패` 줄 수를 한 줄로 적는다. 당김(BASE −Z
  40mm 당겨 떼기) 하나만 실패해도 실행기는 무시하고 후퇴·배치를 그대로 계속하므로 결과 칸에는 영향이
  없다 — 별도 기록일 뿐이다.
