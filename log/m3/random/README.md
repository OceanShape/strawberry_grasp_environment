## 배치별 정성 기록 — 그 배치에서 처음 드러난 것

배치마다 한 단락. 형식: **무엇이** (과실·좌표·로그 줄) → **왜** (원인 코드 위치, 실기 노드인지 시뮬 손잡이인지) → **시연 배치에서 안 보였던 이유** → **처리** (기록 / 시뮬 수정 / 고치지 않음).

- **공통 1 — 보드 가장자리 위쪽 과실은 실기 파지 경로가 닿지 않는다 (5 배치 전부, 8개)**: 과실 중심 z 790~897mm 이고 |x| ≥ 185mm 인 익은 과실 8개는
  파지 후보(오프셋 3~5 × 자세 4 = 12~20개)가 **전부 `MotionGenStatus.IK_FAIL`**(pre-approach 목표 y 487~491mm) → `ABORT: grasp 전체 실패`. 반면 가운데 x 127 z 784·x 113 z 827 은 잡았다 —
  z 하나가 아니라 **x·z 조합(도달 포락선)**이다. IK 는 플래너의 cuRobo(실기 설정)에서 실패했고 시뮬 로봇 모델과 무관하다.
  실기 노드에는 높은 과실 처리(`NW_HIGH_TARGET_*`, z ≥ 750mm)가 있지만 `measured_tcp_260mm` 프로파일에만 걸려 있고, 그 프로파일은 URDF 에 `grasp_tcp_link` 가 없어 로드되지 않는다(09-08 확인).
  파일럿 로그에 그 처리 줄은 0(audit B6 확인). 시연 배치의 익은 과실 최고 z 는 760mm 라 한 번도 안 보였고, 계획서의 "z 0.90 = 런 12~14 로 검증된 높이"는 틀렸다(검증된 것은 0.76).
  **처리: 고치지 않는다(§0-1), 배치 범위도 좁히지 않는다(가리는 것). `portfolio/H_scope_decisions.md` §10 사례 5.** 실기 로봇이 같은 과실을 못 잡는지는 확인하지 못했다.
- **공통 2 — 이송 거부는 시연 배치와 같은 가드에서 난다**: 배치 실패 13건 = J6 spline jump(±225 창) 10 · J3 스윙 2(176.3·177.7° > 120°) · J6 스윙 1(배치 3, 180.1° > 180° — 0.1° 차, 새 사유). 전부 실기 원본 가드 값이고 기록만.
- **공통 3 — 분할은 배치마다 다른 분면에서 났다**: se / ne / nw·se / sw / ne·sw. 세부 칸 18 = 실기 평면 12 · 부모 거리 3 · IK 해 없음 퇴화 3(전부 ne 위쪽 칸, 오프라인 예측과 같은 부류). 임계값 3 은 시연 배치 맞춤이 아니라 후보가 몰린 분면이면 어디든 쪼갠다.
- **공통 4 — 끝 쪽 사다리 분기가 시연 범위 밖에서 돌았다**: 시연 배치의 익은 과실 x 는 −380~+280 이었다. 파일럿에서 왼쪽 끝 사다리(x < −0.30)는 x ≈ −405(z 469, 배치 5)를, 오른쪽 사다리(x > 0.25, 오프셋 5)는 x 416(z 609, 배치 3)을 잡았다. 높이만 넘지 않으면 가장자리도 닿는다.
- **시드 1**: 공통 1 한 건(x −302 z 816). se 분할 2칸 실기 평면(Δ33.3·34.3°). 배치 실패 3 전부 slot 3 J6 spline jump. 낙하 3 전부 바닥.
- **시드 2**: nw 에 익은 과실 0 → **가지치기가 시연 배치와 다른 분면(nw)에서 났다**. ne 후보 4 → 분할, 아래 칸 1 실기 평면(Δ57.5°, 한도 60 근처), 위쪽 칸 2 IK 해 없음 → 부모 자세. 공통 1 두 건(x 187 z 897·x 383 z 871). 왼쪽 끝 과실(x −368)의 첫 파지 후보가 **J1 스윙 191° > 75°**(반대 분기)로 거부됐으나 다음 후보(J1 139°)로 잡았다 — 가드가 설계대로 후보를 걸러 넘어간 사례.
- **시드 3**: nw·se 두 분면 분할(5칸 전부 실기 평면, Δ19.6~56.9°). 공통 1 한 건(x −404 z 811 — 왼쪽 끝이면서 높음). 배치 실패 4: J6 swing 180.1(새 사유)·J3 swing 176.3·J6 spline 2. 배치 3/7 로 파일럿 최저 — 이유는 전부 이송 가드.
- **시드 4**: sw 후보 4 → 분할, 실기 평면 2 + 부모 거리 1(sw/ne, Δ26.2° — 런 12·14 와 같은 칸). 공통 1 두 건(x −240 z 860·x 351 z 790, 오른쪽 사다리 5 오프셋도 전부 IK_FAIL). 파지 실패 뒤 스캔 자세 복귀 계획이 J6 spline jump 로 한 번 거부된 뒤 진행. 배치 5/6 로 파일럿 최고.
- **시드 5**: ne·sw 두 분면 분할 — **부모 거리 단계가 한 런에 2칸**(ne/se Δ23.3°·sw/ne Δ26.2°), ne/nw 위쪽 칸은 IK 해 없음 → 부모 자세. 공통 1 두 건(x −185 z 854·x 248 z 868 — 포락선의 가장 가운데 쪽 실패). 배치 실패 3: J6 spline 2(slot 1 두 번)·J3 swing 177.7(왼쪽 끝 x −396). 낙하 3 전부 바닥.

**"T4d 전에 직선 진입 IK 실패 원인을 확인한다" 항목 판정 (09-15)**: 파일럿 5 런 32 파지에서 `ABORT: 직선 진입 실패` 0, 브릿지 `MoveLine IK Failed` 0. 런 10~14 까지 합쳐도 런 12 한 건(ripe_08)뿐이고
런 14 는 같은 과실을 다른 pre-approach 해로 잡았다. cuRobo 해 선택의 간헐성이지 배치 조건과 무관하므로 **선행 항목으로 둘 필요가 없었고, T5 전에도 필요 없다.** `portfolio/E_metrics.md` 미해결 표에 "간헐, 재발 시 브릿지 IK 로그로 원인 관절 확인"으로 남긴다. 별도 작업 없음.
공통 1 의 미파지는 이것과 다른 실패다 — 직선 진입까지 가지 못하고 pre-approach 목표에서 IK 해가 없다.

## 결론

1. 서로 다른 과실 배치 5개에서 시퀀스가 사람 손 없이 끝까지 돌았다. 방어선 발동 0, 낙하 13개 전부 바닥 정지, 카운트 일치 5/5.
2. 배치 실패 13건은 시연 배치와 같은 실기 가드에서 났다. 새로 드러난 것은 보드 가장자리 위쪽 도달 포락선(미파지 8, H §10)이고, 끝 쪽 사다리 분기는 시연 범위 밖 x −405·+416 까지 동작했다.
3. 적응 분할은 배치마다 다른 분면에서 났다(se / ne / nw·se / sw / ne·sw). 임계값 3 이 시연 배치 맞춤이라는 지적에 대한 답이다.
